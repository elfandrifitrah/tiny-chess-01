A compact chess engine in 4,096 bytes of Python: 0x88 board, alpha-beta search with quiescence, a Zobrist transposition table, killer moves, history ordering, null-move pruning, PVS, late-move reductions, piece-square tables, and a fixed node budget. The readable source is packed with makefun compress into main.py. It plays the house gauntlet over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
